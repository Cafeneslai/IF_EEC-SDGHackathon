## 🎯 เกี่ยวกับโครงการ (About the Project)

พื้นที่เขตพัฒนาพิเศษภาคตะวันออก (EEC: ชลบุรี, ระยอง, ฉะเชิงเทรา) มีศักยภาพสูงแต่มักประสบปัญหานักท่องเที่ยวกระจุกตัวในแหล่งท่องเที่ยวยอดนิยม โครงการ **EEC GoFlow** จึงถูกพัฒนาขึ้นเพื่อใช้ **ปัญญาประดิษฐ์ (AI)** ในการสร้างแผนการเดินทางแบบเฉพาะบุคคล (Personalized Tourism) โดยวิเคราะห์จากความต้องการของผู้ใช้ สภาพอากาศจริง และความหนาแน่นของสถานที่ เพื่อกระจายนักท่องเที่ยวสู่แหล่งท่องเที่ยวรองและวิสาหกิจชุมชน ช่วยขับเคลื่อนเศรษฐกิจท้องถิ่นและส่งเสริมการท่องเที่ยวอย่างยั่งยืนตามหลัก SDG

## ✨ ฟีเจอร์เด่น (Key Features)

- 🔐 **ระบบสมาชิก & Dashboard (Gamification):** สมัครสมาชิกและล็อกอิน พร้อมหน้า Dashboard ส่วนตัว โชว์ประวัติทริป, สถิติ SDG Points, และกราฟคะแนนรักษ์โลกเฉลี่ย (Eco-Score)
- 🤖 **100% AI-Driven Itinerary:** จัดแผนการเดินทางแบบรายวัน (เช้า-เย็น) โดยโมเดล **Ollama (Llama 3.1)** ที่ทำงานแบบ Local ปลอดภัยและปรับแต่งได้
- 💬 **ผู้ช่วยส่วนตัว AI (น้อง GoFlow Chatbot):** แชทบอทลอยมุมจอที่ฝัง Persona "น้อง GoFlow" ช่วยตอบคำถามเรื่องเที่ยวและแนะนำ Eco-tips แบบ Real-time ตลอดการใช้งาน
- 🌤️ **Weather-Aware AI:** ระบบจะดึงพยากรณ์อากาศแบบ Real-time (เช่น ฝนตก, ร้อนจัด) และฤดูกาล เพื่อให้ AI ปรับเปลี่ยนแผนให้เหมาะสม (เช่น หากฝนตก AI จะเลือกพิพิธภัณฑ์แทนทะเล)
- 🔄 **Smart Alternative (AI Regenerate):** หากจุดหมายมีคนเยอะหรือผู้ใช้ไม่ถูกใจ สามารถกดปุ่มสุ่มใหม่เพื่อให้ AI หาสถานที่ทดแทนที่คนน้อยกว่าในบริบทเดียวกันได้ทันที
- 🌿 **Eco-Routing (SDG Focus):** AI แนะนำวิธีการเดินทางที่ลดคาร์บอนระหว่างสถานที่ (เช่น EV Bus, เดิน) พร้อมประเมิน Eco-Score รวมของทริป
- 🛍️ **Local Discovery:** ระบบบังคับแทรกสถานที่ที่เป็นสินค้า OTOP หรือวิสาหกิจชุมชน อย่างน้อย 1 แห่งต่อวัน พร้อมเล่าเรื่องราวอัตลักษณ์เพื่อเพิ่มรายได้ให้ท้องถิ่น
- 🗺️ **Smart Map (Leaflet):** แผนที่ Interactive แสดงหมุดสถานที่จริง ดึงพิกัด (Lat/Lng) จากฐานข้อมูล พร้อมแยกสีตามหมวดหมู่
- 📸 **Share Trip (Export to Image):** ผู้ใช้สามารถกดแชร์แพลนทั้งหมดออกมาเป็นรูปภาพสวยงามเพื่อแชร์ลง Social Media ได้ทันที
- 🎨 **Premium Glassmorphism UI:** ดีไซน์หน้าเว็บล้ำสมัย หรูหรา สไตล์กระจกฝ้า พร้อมระบบเปลี่ยนธีมสี (Color Themes)
- 🎁 **SDG Rewards Store:** ระบบแลกคะแนนรักษ์โลก (SDG Points) เป็นส่วนลดร้านค้า OTOP หรือตั๋วโดยสารสาธารณะ สนับสนุนเศรษฐกิจชุมชนและลดคาร์บอน
- 🧩 **Drag & Drop Itinerary:** ผู้ใช้สามารถลาก-วาง สลับลำดับสถานที่ในแผนการเดินทางได้อย่างอิสระผ่านระบบ HTML5 Drag and Drop
- 😷 **Live AQI & Weather Alert:** ดึงข้อมูลฝุ่น PM2.5 แบบ Real-time พร้อมแสดงป้ายเตือนหากอากาศเป็นพิษ เพื่อแนะนำให้สลับไปสถานที่ในร่ม
- 🎭 **AI Travel Persona Quiz:** แบบทดสอบจิตวิทยาสั้นๆ ก่อนสร้างแพลน เพื่อวิเคราะห์สไตล์การเดินทางและกรอกแบบฟอร์มให้อัตโนมัติ

## 🏗️ สถาปัตยกรรมระบบ (System Architecture)

ระบบถูกออกแบบเป็น Microservices 3 ส่วนหลักเพื่อการขยายตัว (Scalability):

1. **📱 Frontend (`eec-goflow-frontend/`)**
   - **Tech Stack:** React 18, Vite, TailwindCSS, React Router v6, Leaflet, html2canvas
   - **หน้าที่:** จัดการ UI/UX สุดพรีเมียม และรับคำสั่งจากผู้ใช้
2. **⚙️ Backend (`eec-goflow-backend/`)**
   - **Tech Stack:** Node.js 20, Express.js, Prisma ORM, SQLite
   - **หน้าที่:** จัดการฐานข้อมูล (Users, Locations, Trips), ดึงสภาพอากาศ (Open-Meteo API), และเป็นตัวกลางเชื่อมต่อ AI
3. **🧠 AI Service (`eec-goflow-ai/`)**
   - **Tech Stack:** Python 3.11, FastAPI, Pydantic, Ollama (Llama 3.1)
   - **หน้าที่:** สมองกลประมวลผล Prompt, วิเคราะห์ข้อมูล และคืนค่ากลับมาเป็นรูปแบบ JSON (พร้อมระบบ Auto-Retry หากตอบกลับผิดรูปแบบ)

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

### 📋 สิ่งที่ต้องมีในเครื่อง (Prerequisites)
- [Node.js](https://nodejs.org/) (v18 หรือใหม่กว่า)
- [Python](https://www.python.org/) (3.10 หรือใหม่กว่า)
- [Ollama](https://ollama.com/) (ต้องติดตั้งโปรแกรมและโหลดโมเดลแล้ว โดยรันคำสั่ง `ollama run llama3.1` ทิ้งไว้ 1 ครั้งเพื่อให้โมเดลอยู่ในเครื่อง)

### 💻 ขั้นตอนการรันระบบ (รันแยกกัน 3 Terminal)

**Terminal 1: รัน AI Service (Python)**
```bash
cd eec-goflow-ai
pip install fastapi uvicorn pydantic ollama
fastapi dev main.py
# เซิร์ฟเวอร์จะรันที่ http://127.0.0.1:8000
```

**Terminal 2: รัน Backend (Node.js)**
```bash
cd eec-goflow-backend
npm install

# ซิงค์ฐานข้อมูลและสร้างตาราง
npx prisma db push --force-reset

# เพิ่มข้อมูลจำลอง (สถานที่, OTOP, ผู้ใช้ทดสอบ) ลง Database
node seed.js

# รันเซิร์ฟเวอร์
node index.js
# เซิร์ฟเวอร์จะรันที่ http://localhost:3000
```

**Terminal 3: รัน Frontend (React)**
```bash
cd eec-goflow-frontend
npm install
npm run dev
# หน้าเว็บแอปพลิเคชันจะเปิดที่ http://localhost:5173
```

## 💡 วิธีนำเสนอ (How to Pitch & Demo)

1. **เข้าสู่ระบบ:** ไปที่มุมขวาบน กดปุ่มเข้าสู่ระบบ (สามารถใช้เมล `test@example.com` รหัสผ่าน `password123` ที่มีให้แล้ว)
2. **สร้างแพลน (Onboarding):** เลือกจังหวัด, ระบุอายุ, งบประมาณ, สไตล์การเที่ยว และกดให้ AI สร้างทริป (แนะนำให้เลือก 2-3 วันเพื่อโชว์แท็บรายวัน)
3. **จุดประกายความว้าว (Core Features):**
   - ชี้ให้กรรมการดู **งบประมาณรวม** และ **Eco Score** ที่ AI คำนวณให้
   - อธิบายว่า AI จัดแพลนโดยอิงจาก **สภาพอากาศปัจจุบัน** และบังคับใส่ **ร้าน OTOP** ให้แล้ว
   - ลองกดปุ่ม **"สุ่มสถานที่ใหม่" (🔄)** เพื่อโชว์ฟีเจอร์ Smart Alternative (AI จะคิดสถานที่ทดแทนที่คนน้อยกว่าให้ทันที)
4. **โชว์ความล้ำ (Chatbot & Dashboard):**
   - กดปุ่มแชทมุมขวาล่าง พิมพ์คุยกับ **"น้อง GoFlow"** โชว์ให้เห็นว่าแอปโต้ตอบสดๆ ได้ และเน้นเรื่องรักษ์โลก
   - กดที่ชื่อผู้ใช้มุมขวาบน เพื่อพาไปหน้า **Dashboard** โชว์กราฟวงกลม Eco-Score และประวัติทริป (Trip History)
5. **แผนที่และแชร์:** เปิดแถบแผนที่โชว์หมุดสถานที่ และกดปุ่ม **"แชร์ทริป (Export รูปภาพ)"** ด้านล่างสุด
